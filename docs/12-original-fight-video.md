# 12. 원작 낚시 연출 프레임 분석 (2026-10-17)

사용자가 준 원작 플레이 영상(`cpmw_fighting_video.mp4`, 17분 17초, 1920×1080, 12fps — 홍현 앞바다 CH.1, 배 위, 밤 → 새벽 노을)을
**한 판 전체(0:16~2:04)는 0.5초 간격, 장면이 바뀌는 순간은 프레임(0.083초) 단위**로 보고 솔로판 연출을 맞춘 기록이다.
나머지 15분은 4초 간격으로 훑어 같은 흐름이 반복되는지, 다른 장면(지도·도감·수리·내 캐릭터 창)이 있는지 확인했다.

원작 그래픽·로고·글꼴은 쓰지 않는다. 구도·순서·시간·색만 따라 하고 그림은 직접 만든다
(예: 원작의 붓글씨 COUNTER는 게임 글꼴 + 먹색→흰색→금색 그라데이션으로).

뽑은 프레임은 저장소에 넣지 않는다 (영상은 사용자 PC에만 있다). 다시 보려면:

```bash
python -m venv <scratch>/venv && <scratch>/venv/Scripts/python -m pip install opencv-python-headless numpy
# 시작초 끝초 간격 → 4×4 모아보기 jpg
python sheets.py <영상> <출력폴더> 36.0 44.0 0.16667 4 4 480
```

## 2. 화면 색 (밤)

원작의 밤은 검지 않고 **보랏빛 남색으로 밝다** (바위·물결·캐릭터가 또렷하다). 솔로판은 밤이 거의 검어서
`DayNightCycle`의 밤 하늘·환경광을 `(0.04, 0.06, 0.13)` → `(0.12, 0.13, 0.26)`, 달빛 0.28 → 0.5, 밤하늘 노출 0.12 → 0.3, 밤 구름을 밝게 바꿨다.
