### 2026-10-15: 해안 낚시터 8곳 · 기본 동작 · 버그 정리

- **기본 동작**: Kevin Iglesias Human Basic Motions FREE의 Idle01·Walk01·Run01·Sprint01(남·녀)을 `Resources/Animations/KevinIglesias`로. 걷기 키 4.5m/s는 Run 클립 ×1.1, 달리기 7.5m/s는 Sprint ×1.25 (원래 속도는 [RM] 판으로 잼). 10 문서 7장.
- **해안 맵 틀** `World/CoastMap.cs`(`CoastSpec` → `CoastMapDef` + `CoastWorldBuilder`), 사양 `World/KoreaCoasts.cs`, 공용 소품 `World/CoastProps.cs`(서천도 이걸 쓴다). 03 문서 "새 맵 추가"에 항목 표.
- **새 어종 13종**(동해 8·남해 4·서해 1) + 기존 바다 어종 서식 범위 확장, 업적 8개, 에기는 서해·동해에서 판다.
- **버그** (감사 에이전트 + 스크린샷 점검): 만조 때 해안 맵에서 플레이어가 멈춤(평균 수면 기준으로 판정), 물에 잠긴 모래톱·갯벌에서 고립(해안으로 구조 + 물 들기 전 경고), 못 깨는 일일 의뢰(그 맵 격자에 있는 서식지만), 낚시터 목록 도감 달성도가 전체 도감 수로 계산됨, 레벨 업·칭호를 바꿔도 머리 위 이름표 그대로, 미끼 칸 6개라 에기·루어가 잘림(→ 8칸), 바다의 '먼바다' 서식지 이름이 먼바다 포인트와 같음(→ '깊은 바다'), 자동 스크린샷에서 시계를 돌리면 날씨 고정이 풀림, 겨울 알림이 어느 맵에서나 '한강이 얼었다', 시작 알림이 늘 '한강'.
- **사실성** (플레이 화면 점검): 물가 거품·얕은 물(해저 높이 텍스처, 03 문서 "물"), 찌 궤적에 등대·NPC·건물·나무·언덕이 있으면 못 던짐(조준 링 빨강), 사람·건물·나무·가로등·배경 배 콜라이더, 배가 물 위 물체를 뚫지 않음, NPC 낚시꾼 낚싯줄·찌, z-fighting(카메라 near 0.2, 지형 LOD 2, 판 높이·엇갈림), 간판 단면·양면, NPC 곁 내 이름표 숨김, 자동 연출 장면 위치(홍현 등대 앞·등대섬 NPC와 겹침) 수정 + `[Dev] 캐스팅 막힘` 로그, 파이팅 중 물고기가 방파제·땅 위로 그려지지 않게(좌우 폭을 물 위로 줄임), 방파제 파도막이 벽 1.2→0.8m(1인칭 화면을 가렸다), 긴 알림은 두 줄로 감싸기(화면 밖으로 넘쳤다).
