# 07. 원작 데이터 검증 (2026-10-13)

사용자가 Gemini에게 받은 「청풍명월 사전」 7개 파일(SYSTEM, EQUIPMENT, ECOLOGY, ECONOMY, COSTUME, BAIT_ECOLOGY, GUILD)을 기사·위키·공략 블로그·유저 영상과 대조했다.
이 프로젝트는 **확인된 것은 원작대로**, 확인되지 않은 것은 "원작풍"으로만 쓰고 수치는 우리 밸런스에 맞춘다.

## Gemini 자료 중 확인되지 않았거나 틀린 것

| 주장 | 판정 | 처리 |
|---|---|---|
| 강화 실패 시 **장비 파괴** / 0강 초기화 | **틀림** (개발실장: 깨지지 않음) | 쓰지 않음 |
| 강화 단계별 성공률·스탯 표 | 확인 안 됨 | 우리 수치 사용 (최대 15강은 원작대로) |
| 낚싯바늘 행동력 (5분 충전, 최대 30개) | 확인 안 됨 | 쓰지 않음 (솔로판엔 체력 시스템이 이미 있음) |
| 장비 이름·수치 표 (견습공의 나무 낚싯대, 블랙스톰 릴 …) | 확인 안 됨 | 거거 낚시대·나팔고둥만 원작 이름으로 쓰고 나머지는 우리 이름 |
| 미끼 이름 (하급혼합미끼, 어분덩이, 비릿한볼살, 기름진어묵, 뭉개진서더리 …) | 이름 체계는 사실(촉촉한이리), 개별 이름은 확인 안 됨 | "원작풍" 해체 미끼로 사용 |
| 의상 부위별 능력치 (상의=대어 확률 …) | 확인 안 됨 (능력치 의상 자체는 사실) | 우리 설계로 부위별 능력치 |
| 제우스·포세이돈·풍림화산 세트, 백상아리 히든 보스, 만렙 55 지중해 레이드 | 만렙 55·**풍림화산은 사실**(코인 이벤트 채비), 나머지 확인 안 됨 | 풍림화산 낚싯대·릴을 대물 코인 교환품으로 (11 문서) |
| 낚싯바늘 | 모바일판의 소모 자원은 사실, 온라인판은 나중에 "바늘" 채비 항목이 추가됨 | 쓰지 않음 |
| 조합(길드) 레벨 1~10 버프 수치 | 길드 존재는 사실, 수치 확인 안 됨 | 솔로판에선 쓰지 않음 |
| 챔질 등급별 초기 HP 차감 (P 15%, Gr 8%, Go 4%) | 확인 안 됨 | 원작풍으로 채택 (손맛 강화) |
| 장력 빨강 1.5초 버티면 끊김 | 확인 안 됨 | 우리 규칙 유지 (0.4초) |
| 홍현 보스 자바리, 무지개멸 | 무지개멸은 "Lv.11 보스급 도전"으로 체험기에 나옴, 장소 확인 안 됨 | 홍현의 대물은 **자이언트 그루퍼(자바리)** 로 — 그루퍼 퀘스트는 사실. 무지개멸은 넣지 않음 |
