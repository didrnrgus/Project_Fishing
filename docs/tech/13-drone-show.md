# 13. 드론 라이트쇼 3,000대

[← 기술 문서 목차](README.md) · 코드: `Assets/Scripts/World/DroneShow.cs`(`DroneShow`·`DroneArt`·`DroneConfig`), `tools/drone/`(`drone_points.py`·`scene.py`·`title_scene.py`) · 플레이어 설명: [가이드 08](../guide/08-drone-show.md)

탄천 맵의 밤하늘(탄천종합운동장 위)에 드론 3,000대가 그림을 그린다. 참고는 실제 성남페스티벌 드론쇼(3,000대). 장면을 10초 보여 주고 5초 동안 날아가 다음 장면이 된다.

| 해결한 문제 | 기법 |
|---|---|
| 3,000개 빛 점을 싸게 그리기 | 파티클 시스템 하나 + `SetParticles` (드로우 콜 1) |
| 그림 → 드론 자리 | 배경 자동 제거(가장자리 색 K-means) + 가중 K-means로 3,000점 고르게 |
| 장면 전환 때 무리가 엉키지 않게 | 무작위 순서 탐욕 최근접 짝짓기 |
| 진짜 드론쇼 같은 움직임 | 물결 출발(좌→우 지연) + smoothstep + 3D로 부푼 호 + 둥둥 떠다님 |
| 윤곽이 또렷한 그림 | 이웃 쏠림·색 대비로 윤곽 점 찾기 → 크게·밝게, 빛 줄기가 훑고 지나감 |
| 빌드 뒤에도 장면 교체 | 점 파일(JSON) 폴더 + `droneshow.json` 설정 덮어쓰기 |

## 1. 드론 = 파티클 하나

드론은 3D 공간의 빛 점일 뿐이다. GameObject 3,000개 대신 `ParticleSystem` 하나(`maxParticles = 3000`, 시뮬레이션 끔)에 매 프레임 위치·색·크기를 직접 써 넣는다.

```csharp
_parts[i].position   = Vector3.Lerp(Ground(i), p + bob, _on);    // 낮엔 땅의 대기 자리로 내려앉는다
_parts[i].startColor = new Color(c.r * dim, c.g * dim, c.b * dim, c.a * _on);
_parts[i].startSize  = 1.5f * (1f + 0.18f * edge + 0.8f * edge * glow + 0.12f * glow);
_ps.SetParticles(_parts, N);
```

- 셰이더는 야광충과 같은 `Fishing/BioGlow`(더하기 섞기 빛). 겹치면 밝아져 빛 번짐이 저절로 난다.
- 쇼 전체가 "어디에 있나 · 켜졌나 · 무슨 색인가" 세 배열(`_cur`·알파·`_cCur`)로만 표현된다. 꺼진 드론은 알파 0으로 떠 있는다.
- 밤 판정은 전역 셰이더 값 `_FishingNight`. 켤 때 0.6, 끌 때 0.4로 **기준을 따로 둬(히스테리시스)** 해 질 녘 경계에서 깜빡이지 않게.

## 2. 그림 → 점 3,000개 (`tools/drone/drone_points.py`)

1. **배경 자동 인식**: 그림 가장자리 몇 픽셀의 색을 K-means(k=4)로 묶어 배경 팔레트를 만든다 → 팔레트와 가까운 픽셀 중 **가장자리와 연결된 것만** 배경(`scipy.ndimage` 연결 성분). 그림 안의 같은 색은 지우지 않는다.
2. 검은 부분도 끈다(검정 = 드론 꺼짐).
3. 남은 픽셀 좌표에 **가중 K-means(n=3,000)** — 클러스터 중심이 곧 드론 자리. 격자 샘플링과 달리 모양을 따라 고르게 퍼지고(Lloyd 이완과 같은 효과), 가중치로 선이 많은 곳에 점을 더 줄 수 있다(`--edge-boost`).
4. 점마다 그 자리 평균색. 출력 `[[x, y, r, g, b(, 효과)], …]`, 긴 변 = 1로 정규화.

배경이 복잡한 그림은 `scene.py --cutout`이 rembg로 피사체만 딴다. 모델마다 잘 따는 게 달라서 `u2net+isnet-anime`처럼 여러 모델의 마스크를 **합칠** 수 있다(로고는 u2net, 캐릭터는 isnet-anime가 잘 땄다).

## 3. 장면 전환: 누가 어디로 갈지 (`Assign`)

최적 배정(헝가리안 알고리즘)은 3,000×3,000이면 O(n³)로 너무 무겁다. 대신:

```csharp
// 새 장면의 점들을 무작위 순서로 돌며, 아직 안 쓴 드론 중 가장 가까운 것을 짝짓는다
foreach (int k in shuffledOrder) {
    int best = argmin_i(!used[i]) |cur[i] - target[k]|²;
    used[best] = true;  to[best] = target[k];  color[best] = art.C[k];
    delay[best] = ((art.P[k].x + 1) * 0.4 + rand * 0.2) * Wave;   // 왼쪽 점일수록 먼저 출발
}
// 남는 드론은 제자리에서 알파 0으로 꺼진다
```

- **무작위 순서가 핵심**: 정해진 순서(왼쪽부터)로 탐욕 배정하면 뒤쪽 점들이 남은 먼 드론을 받아 화면을 가로지른다. 순서를 섞으면 먼 짝이 고르게 흩어져 무리가 엉켜 보이지 않는다. 시드는 장면 번호로 고정해 늘 같은 쇼가 된다.
- O(n²) = 900만 번 비교지만 장면이 바뀔 때 한 번(15초에 한 번)이라 프레임에 티가 나지 않는다.

## 4. 날아가는 모양

```csharp
float span = Move - Wave;                          // 5초 전환이면: 출발은 0~1초 사이로 물결, 비행은 4초
float k = Clamp01((_t - _delay[i]) / span);
float e = k * k * (3f - 2f * k);                   // smoothstep: 천천히 떠서 천천히 내려앉기
float bump = Sin(e * PI);                          // 가운데서 가장 부푼다
var p = Lerp(from[i], to[i], e) + arc[i] * bump;   // arc: 드론마다 위로 3~8m, 앞뒤로 6~16m 부푼 3D 호
float dim = 1f - 0.45f * bump;                     // 나는 동안 조금 어둡게 → 새 색으로 켜진다
```

- 마지막 드론이 **정확히 `Move`초에** 자리 잡게 비행 시간을 `Move - Wave`로 둔다(사용자 요청: 전환이 정확히 5초).
- 다 날아온 뒤엔 제자리에 박혀 있지 않고 드론마다 제 박자로 위아래 0.4m·옆 0.25m·앞뒤 0.3m 둥둥 뜨고, 판 전체엔 바람 같은 느린 물결. 점 간격이 약 2m라 그림은 안 깨진다.

## 5. 윤곽 빛과 깜빡이 효과

**윤곽 점 찾기** (장면을 읽을 때 한 번, `DroneArt.MeasureEdges`):
- 점 간격 `s` = 가장 가까운 이웃 거리의 **중앙값**(균일 격자 해시로 이웃 찾기). 반경 `2.6s` 안 이웃들을 본다.
- 이웃 벡터 합이 한쪽으로 쏠리면 그림 테두리(구멍 가장자리 포함), 이웃과 색 차이가 크면 색 경계 — 둘 중 큰 값이 윤곽 정도 `E`.
- 윤곽 점은 조금 크고 밝다. 장면을 보여 주는 동안 **대각선 빛 줄기**가 3.4초마다 판을 훑는다 — 앞은 가우시안으로 날카롭고 뒤로 지수 꼬리를 끌어 "쫘르륵" 흐르는 느낌. 늘 하얗게 하면 그림이 바래서(윤곽이 40%쯤) 줄기가 지날 때만 확 타오른다.

**점마다 깜빡이 효과** (점 파일 여섯째 값, 모두 시간의 함수):

| 번호 | 효과 | 식 |
|---|---|---|
| 1 | 반짝 | `0.4 + 0.6·|sin(2.6t + φ)|` |
| 2 | 전광판처럼 달리는 불빛 | `repeat(5φ − 1.2t, 1) < 0.45` |
| 3 | 눈 깜빡임 | 3.4초마다 0.17초 꺼짐 |
| 4 | 일렁임 | 빛 물결이 x를 따라 지나감 |
| 5 | 번쩍 | `sin^14` — 대부분 꺼져 있다가 번쩍 |

장면 끝 1.2초는 전체가 반짝이다가 다음 전환으로 넘어간다.

## 6. 빌드 뒤에도 바꾸는 데이터

- 장면 = 점 파일 하나. 게임 폴더(`StreamingAssets/DroneShow`, 기본 타이틀 장면)와 내 문서 폴더(`문서/짭풍명월/DroneShow`)를 차례로, 폴더 안은 **자연 정렬**(`points_2` → `points_10`)로 읽는다.
- `droneshow.json`은 게임 폴더 기본값 위에 **적은 항목만** 덮는다(`folders`·`scenes`·`holdSeconds`·`moveSeconds`, 환경 변수 펼침). 깨진 파일은 무시하고 로그에 `[DroneShow]`.
- 남의 그림으로 만든 점 파일은 저장소에 넣지 않는다 — 기본 장면은 게임 타이틀 붓글씨에서 뽑은 것뿐(`title_scene.py`).
- 바로 보려면 탄천에서 **N**(낮/밤 바꾸기) → 밤 9시로 넘어가 쇼가 시작된다.
