## 이 문서들을 관통하는 원칙 세 가지

1. **규칙과 표현을 나눈다.** 파이팅·입질·성장 규칙은 MonoBehaviour가 없는 순수 C#이다. 그래서 Unity 없이 수만 번 돌려 밸런스를 잴 수 있었다(01·02).
2. **프레임률에 상관없는 식을 쓴다.** `Lerp(a, b, 1 - exp(-k·dt))`, 감쇠 `x *= exp(-k·dt)`처럼 dt를 지수에 넣으면 30fps든 144fps든 같은 손맛이 난다(01·04·05).
3. **함수 하나로 세계를 정의한다.** 지형은 `HeightAt(x, z)`, 연출은 `Pose(t)`, 입질은 `Weight(어종, 상황)`. 상태를 쌓지 않는 함수라서 테스트·건너뛰기·재현이 쉽다(03·06·09).
