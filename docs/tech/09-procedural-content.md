# 09. 절차적 콘텐츠

[← 기술 문서 목차](README.md) · 코드: `World/LighthouseBuilder.cs`, `World/CoastProps.cs`, `tools/blender/`, `tools/intro/`, `Audio/IntroAudio.cs`, `Audio/SoundFx.cs`, `UI/IntroSequence.cs`

혼자 만드는 프로젝트라 모델러·작곡가가 없다. 그래서 **아트와 소리를 코드로 만든다**. 장점은 고치기 쉽고(숫자 하나), 버전 관리가 되고(텍스트 diff), 같은 틀로 수십 개를 찍어 낸다는 것이다.

## 1. 회전체(lathe) 메쉬

등대처럼 축을 중심으로 둥근 물체는 **옆모습 윤곽선(반지름, 높이) 목록**을 돌려서 만든다.

```csharp
// 방파제 등대 탑: 위로 갈수록 가늘고, 꼭대기 받침(코벨)이 살짝 벌어진다
Part(lh, "Tower", Lathe(28, (0.9f, 0.5f), (0.76f, 4f), (0.62f, 7.5f), (0.62f, 7.5f), (0.84f, 7.78f), (0.84f, 7.78f), (0.84f, 7.86f)), paint);
Part(lh, "Roof",  Lathe(24, (0.7f, 8.95f), (0.7f, 9.03f), (0.7f, 9.03f), (0.52f, 9.25f), (0.28f, 9.45f), (0f, 9.53f)), paint);
```

- 첫 인자는 둘레 분할 수(8이면 팔각 기단, 28이면 둥근 탑).
- **같은 점을 두 번 넣으면 날카로운 모서리**가 된다(`(0.62, 7.5)`가 두 번). 연달아 같은 점 사이에는 면을 만들지 않아 정점이 나뉘고, `RecalculateNormals`가 위·아래 면의 법선을 따로 계산한다. 한 번이면 그 점에서 법선이 부드럽게 이어진다. 점 하나로 "둥근 곳/꺾인 곳"을 고른다.
- 둘레 이음매(첫·마지막 정점이 같은 자리)는 법선을 평균해 세로 줄이 안 보이게 한다.
- 윤곽선 문자열을 키로 메쉬를 **캐시**한다. 등대 열 개를 지어도 메쉬는 하나다.
- 예전엔 원통 프리미티브를 쌓아 "도형 같다"는 지적을 받았다. 윤곽선 몇 줄로 받침·띠·돔 지붕까지 들어간 모양이 됐다.
- 몸통 재질은 콘크리트 텍스처 + 반복 깨기 셰이더([07](07-shaders.md))에 색을 곱해 플라스틱처럼 보이지 않게 한다.

같은 계열의 절차적 메쉬:

| 메쉬 | 방법 |
|---|---|
| 테트라포드 (`CoastProps.TetrapodMesh`) | 위 방향 하나 + 109.47°(정사면체 사잇각)로 기울여 120°씩 돌린 셋 = 다리 4개. 다리마다 뿌리 0.42 → 끝 0.24로 가늘어지는 원뿔대. `TetrapodBank`가 방파제 바깥에 엇갈려 3줄, 바깥 줄일수록 낮게 잠기게 쌓는다 |
| 바위기둥·석회암 봉우리 (`CoastMap.StackMesh`) | 40 × 40 격자 기둥. 서브메쉬 3개: 옆 절벽 / 파도에 젖은 아랫단(짙고 번들) / 위를 보는 턱·꼭대기(풀·이끼) |
| 바위 8종 (`Rocks`) | 정이십면체 구(3번 쪼갬)를 3D 노이즈로 울퉁불퉁하게 → 무작위 평면 몇 개로 깎아 절리면 → 밑을 눌러 평평하게. UV는 삼각형마다 가장 가까운 축으로 투영해 늘어나지 않는다. 처음 쓸 때 8종 만들어 위치로 골라 쓴다 |

## 2. headless Blender 파이프라인 (`tools/blender`)

캐릭터 옷, 물고기 77종, 아이템 아이콘, 해외 소품을 **Blender를 설치하지 않고** 파이썬으로 만든다.

```bash
py -3.13 -m venv bpyenv && bpyenv/Scripts/pip install bpy pillow numpy   # PyPI의 bpy = Blender 모듈
bpyenv/Scripts/python -I tools/blender/build_fish.py --only carp           # FBX + 텍스처 + 아이콘
bpyenv/Scripts/python -I tools/blender/build_fish.py --preview --only carp --out Screenshots/fish
```

### 물고기: 템플릿 + 설계 시트

```python
TEMPLATES = {
    # A. 잉어형: 두툼한 몸, 둥근 등, 작은 입, 꼬리 갈라짐
    'A': dict(depth=0.27, width=0.14, tmax=0.4, body_end=0.8, ped=0.42, arch=0.6, snout=0.6, mouth=-0.1, xsec=2.0,
              fins=[_fin('dorsal', (0.36, 0.72), 0.5, prof=[...]), ...]),
    ...  # B~H 체형, 두족류 O 문어 / Q 갑오징어 / S 오징어
}
```

- 몸은 길이 1 기준 **고리(ring) 64개 × 둘레 40점**. 고리마다 높이·폭을 설계 수치(몸 높이, 가장 높은 위치, 꼬리자루, 등 솟음, 단면 지수)로 정한다.
- 단면 지수 `xsec`: `|x|^n + |y|^n = 1`(초타원). 2면 타원, 작을수록 위아래가 뾰족한 납작한 몸(돔·쥐치).
- 지느러미는 `(시작, 끝, 높이, 제어점 윤곽)`으로. 가시 지느러미는 막을 오목하게 판다.
- 어종 = 템플릿 + 덮어쓸 수치 + 색·무늬. 77종이 **데이터 한 줄씩**이다.
- 뼈와 클립 5종(Swim_Slow/Swim_Fast/Thrash/Flop/Idle_Hover)도 스크립트가 만든다. 오징어·문어는 다리마다 뼈 3개.
- 길이 1m로 만들고 Unity에서 `cm/100`으로 키운다. 그래서 82cm 잉어는 정말 82cm다.

### 확인 루프

`--preview`가 옆·위·비스듬히 렌더한 그림, `--sheet`가 전 어종 한 장 시트를 만든다. **눈으로 보는 단계를 자동화**해서 숫자를 고치고 바로 그림을 본다.

### 함정

- bpy 종료 시 충돌 → 스크립트 끝에 `sys.stdout.flush(); os._exit(0)`.
- 전부 다시 만들면 안 바뀐 어종도 FBX·PNG가 바이트 단위로 달라진다 → 바꾼 것만 커밋하고 나머지는 `git checkout --`.
- Mixamo 동작은 `mixamo_probe.py`가 막대 인형 시트·움직임 곡선·루프 후보를 그려서, 긴 클립을 어디서 자를지 눈으로 정한다.

## 3. Karplus-Strong: 뜯는 현 소리

타이틀 음악의 가야금풍 선율은 녹음이 아니라 **계산**이다.

```csharp
int len = Mathf.RoundToInt(Rate / f);                // 지연선 길이 = 한 주기 샘플 수
var buf = new float[len];
float lp = 0f;
for (int i = 0; i < len; i++) { lp += (Noise() - lp) * 0.55f; buf[i] = lp; }   // 낮게 거른 잡음으로 채움

for (int i = 0; i < dur; i++)
{
    int next = (idx + 1) % len;
    float y = buf[idx];
    buf[idx] = decay * 0.5f * (buf[idx] + buf[next]);    // 이웃 두 샘플 평균 = 저역 통과 필터
    idx = next;
    float body = y * (1f - Mathf.Exp(-t * 400f));         // 뜯는 순간의 딱딱함을 조금 누른다
    // … 좌우 팬 게인 gl/gr로 스테레오에 더한다
}
```

- **원리**: 잡음으로 채운 원형 버퍼를 돌면서 이웃 평균으로 덮어쓴다. 버퍼 길이가 음높이(주기)를 정하고, 평균이 고음을 빨리 깎아 **현처럼 밝게 시작해 둥글게 사라지는** 소리가 저절로 난다.
- 시작 잡음을 미리 낮게 걸러(`lp`) 쇠줄이 아니라 **비단 줄** 같은 부드러운 소리를 낸다.
- `decay`를 음높이에 따라 바꿔 낮은 음이 더 오래 울린다.
- 팬은 등전력(`√(0.5(1∓pan))`)이라 좌우로 옮겨도 소리 크기가 같다.
- 선율은 평조(솔·라·도·레·미) 5음. 낮은 울림을 천천히 들어오고 끝에서 빠지게 해서 36초 반복 이음매가 티 나지 않는다.
- 계산이 수십 ms 걸려 **작업 스레드**(`Task.Run`)에서 하고, `AudioClip.Create/SetData`만 메인 스레드에서 한다(Unity API는 메인 스레드 전용).

게임 중 소리(`SoundFx`)도 대부분 절차적이다: 릴 감기 루프(속도·장력에 따라 높이·크기), 드랙 루프(줄 풀리는 m/s에 비례), 카운터(휙 → 쿵 → 팅 → 짧은 드랙, 콤보마다 조금씩 높아짐). **게임 수치를 소리 파라미터에 직접 연결**하니 귀로도 상황을 읽는다.

## 4. 연출 = 시간의 함수

인트로(`IntroSequence`)의 모든 움직임은 장면 시각 t의 **순수 함수**다.

```
CompanyPose(t): 0~0.9 검은 막이 걷힘 · 0.45~0.7 낙관이 커졌다 쾅 · 1.1~2.3 붓글씨 · 2.0 금빛 선 · 4.6 어두워짐
TitlePose(t):   0~2.2 밝아지며 카메라가 물러남 · 1.6~3.5 「짭풍명월」 붓글씨 · 3.72 징 …
```

- 상태를 쌓지 않으니 **건너뛰기 = t를 옮기기**다. "다 쓴 상태로 가기"가 `t = 3.6` 한 줄이다.
- 첫 프레임처럼 오래 걸린 프레임 때문에 연출이 튀지 않게 dt를 0.05초로 자른다.
- 소리 사건(쾅, 징)은 t가 사건 시각을 지나면 이름으로 **한 번만** 낸다(`Fire(key, …)`가 `_fired` 집합에 key를 넣고, 이미 있으면 무시). 포즈는 함수지만 "이미 울렸나"만은 상태로 둔다. 건너뛸 때 징은 생략한다.
- 자동 촬영도 `intro.T >= 3.6`처럼 시각으로 기다렸다 찍는다. 재현 가능하다.

### 겹 그림 시차

타이틀 배경은 PIL·numpy로 그린 **겹(레이어) 여러 장**이다(`tools/intro/build_intro_art.py`: 하늘·달·구름·먼 산·물·달빛 길·물안개·가까운 산·배·꽃잎·갈대). 겹마다 시차 계수(하늘 0.1 … 갈대 1.0)를 두고 마우스 위치·느린 흔들림만큼 옮긴다. 가까운 겹일수록 많이 움직여 깊이가 생긴다. 겹은 화면보다 6% 크게 그려 움직일 여유를 둔다.

- 함정: PIL `stroke_width`로 글자를 굵게 하면 윤곽이 겹친 글리프에서 획 속이 지워진다 → 그냥 그린 뒤 `MaxFilter`로 넓힌다.
- 하늘·물 그러데이션은 무압축으로 임포트한다. 압축하면 띠가 진다.

## 옮겨 쓸 때 체크리스트

- 둥근 물체는 lathe. 같은 점 두 번 = 날카로운 모서리.
- 비슷한 것이 많으면 "템플릿 + 덮어쓰기 수치"로 데이터화하고, 미리보기 렌더를 자동화.
- 뜯는 소리는 Karplus-Strong: 지연선 + 이웃 평균. 무거운 계산은 작업 스레드, 엔진 API만 메인.
- 연출은 시간 t의 함수로. 건너뛰기·자동 촬영이 공짜가 된다.
