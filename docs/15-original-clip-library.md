# 15. 원작 기능별 클립 라이브러리 대조 (2026-10-20)

사용자가 준 원작 클립 라이브러리(`Videos/Movavi Library/clips`)를 이 프로젝트 구현과 맞춰 본 기록이다.
이 라이브러리는 원작 영상 13개(약 8시간 20분)를 기능별로 자른 클립 814개와 분석 문서 17개로 되어 있다.
분석 문서는 상태기계·낚시 명세·HUD·배·상점·연출·관찰 수치·작업 분해·QA 등이다.
영상은 사용자 PC에만 있고 저장소에는 넣지 않는다. 원칙은 12·13 문서와 같다.
원작 그래픽·로고·글꼴은 쓰지 않고, 배치·순서·문구 형식·숫자·색만 따른다.

상태 표시: ✔ 원작대로 · △ 솔로판에 맞게 바꿈 · ✕ 안 함(이유) · (기존) = 이번 전에 이미 있던 것.

## 2. 이미 있던 것 (12·13 문서 등) — 클립으로 다시 확인

| 원작 | 솔로판 |
|---|---|
| 조준 링·화살표·큰 거리 숫자, 착수 리플, 입질 `!`, 예신 문구 `손 끝으로부터 미세한 떨림이 느껴집니다.` | (기존) 12 문서 1장 |
| 챔질 클로즈업 + 세로 청록 게이지 → `HIT` → `PERFECT!!!` / `GREAT!!` | (기존) `FightHudView.UpdateHit/UpdateGradeText` |
| 1인칭 파이팅: 원형 텐션 게이지·HP 바·LANDING·거리, 아래 LOW~HIGH 슬라이더, 푸른 원 아이콘(콤보), 주황 데미지 숫자, 노란 발광 로드 + 붉은 비네팅, COUNTER 먹 글씨 + 집중선 + 화살표 | (기존) `FightHudView`, `FightRodView` |
| RESULT: 기록 바 WR/SR/MR, 월척 도장, `FIRST GET`, 살림망/방생 | (기존) `ResultPanel` (WR = 낚시터 최대, TR = 대물 기준, MR = 개인 기록) |
| 로비 4메뉴·지역 선택·로딩·채널 로그·날씨 알림·QUEST LIST·납품·통발·인벤토리·내 캐릭터·도감·수족관·ESC | (기존) 13 문서 |
| 시간대 4단계 · 게임 시계 | (기존) 원작 약 40배속 → 솔로판은 사용자 결정으로 60배속(현실 1초 = 게임 1분) |

## 3. 안 한 것

| 원작 | 이유 |
|---|---|
| 상점 씬(실내 Fishshop·8탭·필터·비교 툴팁) | 솔로판 상점 창(F12)이 같은 일을 한다. 실내 상점 씬은 다음 후보 |
| 보트 카메라 파이팅(뱃머리·계기판이 화면 아래), 스킬 UI(삼각 노드), `N` 챔질 멈춤 | 원작에서도 조건·내용이 확인되지 않음 (docs 11 G2·G9·A10) |
| LP(작은 고기 보상)·RP(순위 점수)·CASH | 솔로판 재화는 GOLD·EXP·소라고동·대물 코인 |
| 동승 보너스, 파티·길드, 타 플레이어 보트·낚싯줄 | 솔로판 (채팅 줄만 `AnglerChatter`로 흉내) |
| 붓글씨 로고·NPC 일러스트·나무 액자 지도 그림 | 원작 리소스. 게임 글꼴·도형·색으로 대신 |
| 클릭 이동 | 왼쪽 클릭이 캐스팅과 겹친다 (13 문서와 같음) |
