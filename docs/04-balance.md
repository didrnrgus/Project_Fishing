# 04. 밸런스

## 시뮬레이션 방법

`Assets/Editor/BalanceSim.cs`가 `FishFight`를 그래픽 없이 돌린다. 플레이어 대신 `FightBot`이 싸운다.

- **FightBot**: 장력 0.72 미만이면 감고, 0.9를 넘으면 푼다. 장력 0.8을 넘으면 낚싯대를 물고기 쪽으로 끌어 늦추고, 0.65~0.8에서는 천천히 겨눈다(드래그 장력). 체력이 남은 고기는 6.5m 안으로 당기지 않는다. 낚싯대는 물고기 반대쪽(±0.8)으로 겨누고, 카운터 찬스에는 확률적으로 카운터를 친다. 랜딩 찬스에는 초당 7회 연타한다.
- **사람처럼 반응 지연을 둔다**: 감기/풀기 판단은 0.25초마다만 바뀐다. 낚싯대 조준은 매 프레임 따라간다.
- 어종마다 길이 3종(하위 25%, 대물 기준, 최대) × 장비 4단계 × 40회를 돌린다.
- 결과는 [balance-report.md](balance-report.md)에 저장된다.

```bash
sh tools/balance.sh              # 전체
sh tools/balance.sh -simSummary  # 대물 기준/최대 길이만
```

### 해석
- 원작 영상의 잉어 44cm 파이팅이 약 40초였다. 대물이 20~35초로 비슷한 손맛 길이다.
- 작은 고기는 장비와 관계없이 잡힌다. 대부분 거리를 좁히고 랜딩 연타하는 시간이다.
- 대물을 입문 장비로 노리면 줄이 자주 끊긴다 → **장비를 사야 하는 이유**가 생긴다.
- 상급(연조)과 대물(경조)은 의도적으로 성격이 다르다.
  - 연조: 충격을 흡수해서 거의 안 끊기지만 느리다. 장력이 낮게 유지돼 가끔 바늘이 빠진다.
  - 경조: 데미지가 크고 빠르지만, 질주할 때 장력이 튀어 끊길 수 있다. 대신 비거리가 32m라 데크 끝에서 깊은 칸까지 닿는다.
- **바다 어종**은 민물 대물과 비슷한 20~30초. 돌돔·참돔 최대 크기는 입문 장비에서 85~90%라 장비를 바꿀 이유가 된다.
- **다금바리·돗돔**(홍현 먼바다 전용 전설, 2026-10-14 추가): 다금바리는 그루퍼급. 돗돔 190cm는 입문·중급으로는 못 올리고(줄 끊김) 상급 이상에서 65~90% — 배 타고 먼바다까지 나가는 끝판 고기로 의도. 무게는 언론 보도(165cm 90kg)에 맞춰 계수 0.02.
- **자이언트 그루퍼**(대물 퀘스트 보스)는 입문·중급(경조 카본) 장비에서 30~70%로 어렵고, 상급(연조)·대회·강화 장비로 90~100%. 경조 카본대는 그루퍼의 질주에 장력이 튀어 입문대와 비슷하게 끊긴다(의도: 보스는 연조대나 강화로).
- **강화 +10~+15와 의상**을 다 갖추면 파이팅이 약 30~40% 짧아진다. 끝까지 키운 보상이지만 손맛이 사라지지 않게 강화 1단계당 힘을 +3%로 낮췄다(5차).
- 봇은 체력이 남은 고기를 5m 안으로 당기지 않는다("도망간다" 규칙). 사람이 이 규칙을 모르고 계속 감으면 시간이 더 걸린다.

## 조정 이력

| 시점 | 문제 | 조치 |
|---|---|---|
| 1차 | 봇이 모든 어종을 입문 장비로 100% 잡음. 장비 의미 없음 | 반응 지연 0.25초 도입, 풀기 시 장력 ×0.25→×0.45, 돌진 배율 1.7→2.1, 돌진 확률 0.15→0.25×공격성, HP ×1.25 |
| 2차 | 상급(연조)이 대물 장비보다 성공률이 높고, 중급(경조)이 입문보다 나쁨 | 경조 장력 반응 속도 10→7, 연조 4, 연조 흡수 0.25→0.2, 대나무대 힘 1.6→1.5·연조 0.9→0.75, 헤비대 경조 0.2→0.35 |
| 3차 (원작 영상 반영) | 원작 규칙 추가: 질주 카운터, 체력 높은 고기 5m 안 도망, 랜딩 연타 | 봇에 "5m 안으로 당기지 않기", 초당 7회 랜딩 연타 추가. 파이팅 시간이 원작 영상과 비슷해짐 |
| 4차 (드래그 장력) | 마우스를 물고기 반대쪽으로 끌면 장력이 쌓이고 물고기 쪽으로 끌면 늦춰지게 바꿈 | 봇이 늦추기를 쓰게 되어 전체 줄 끊김 340 → 63회, 평균 성공률 94.6% → 98.4%. 대신 무작정 반대쪽으로 당기는 사람은 더 잘 끊긴다. 황금 비단잉어 100~110cm는 입문·중급 장비에서 여전히 65~75%라 장비 의미는 유지 |

| 5차 (바다·강화 +15·의상·대회 장비) | 강화 단계당 낚싯대 힘 +5%·릴 +4%면 +15·의상 장비에서 대물 파이팅이 5~9초로 손맛이 없음 | 강화 단계당 낚싯대 힘 +3%, 릴 감기 +2.5%. 시뮬레이터에 대회·강화·의상 단계 추가. 그루퍼는 그대로(보스) |
