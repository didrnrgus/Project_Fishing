# 11. 원작 자료 대조표 (2026-10-15)

사용자가 정리한 원작 자료집(`plan/` 01~11, sources.md — 2010~2013 기사, 2013 공략 블로그, 유튜브 화면, 나무위키 발췌)을
이 프로젝트의 구현과 하나씩 맞춰 본 표다. 자료집의 신뢰도 표시를 그대로 옮겼다:
✅ 여러 자료로 확인 · 🔸 한 자료 · 👁 영상 화면에서 직접 봄 · ❓ 확인 안 됨/자료끼리 다름.

구현 상태: **✔ 원작대로** · **△ 원작풍(솔로판에 맞게 바꿈)** · **✕ 안 함(이유)**.
원작 리소스(이름 일부를 뺀 그래픽·사운드·로고)는 쓰지 않는다. 사실(규칙·지명·어종 이름)만 참고한다.
