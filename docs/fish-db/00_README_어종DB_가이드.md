## ⚠️ 먼저 읽어주세요

- 이 문서의 어종은 **청풍명월 원작 데이터가 아닙니다.** 원작의 맵별 어종표는 구하지 못했습니다.
- 대신 **각 낚시터가 실제 어디인지(한강, 앙코르와트, 푸켓, 산토리니 등) 알려져 있으므로, 그 지역에 실제로 서식하는 어종**을 조사해 정리했습니다.
- 원작에서 확인된 어종(돗돔, 다금바리, 참돔, 돌돔, 상어류, 황새치, 폭군삼치, 괴물가물치, 빙어 등)이 해당 맵에 있었는지는 확인하지 못했지만, 실제 생태와 겹치는 것은 해당 행에 표시했습니다.
- **희귀도(R), 파워(P), 경계심(W)은 제가 정한 추정 점수**이며 공식 수치가 아닙니다. 게임 밸런스에 맞게 조정하세요.
- 크기, 습성은 일반 생태 지식과 아래 출처를 바탕으로 한 **대략값(≈)** 이고, 문헌마다 차이가 있습니다.

## 희귀도 (R) 기준

| R | 이름 | 기준 |
|---|---|---|
| ★1 | 흔함 | 현지에서 흔히 잡히는 소·중형 어종, 개체수 풍부 |
| ★2 | 보통 | 대상어로 알려진 어종, 중형 중심, 비교적 쉽게 만남 |
| ★3 | 드묾 | 대물이거나 포인트·시기·조건이 제한됨 |
| ★4 | 희귀 | 대형 포식자, 개체수 감소, 잡기 까다로움 |
| ★5 | 전설 | 멸종위기·보호종·초대형·사실상 사라진 어종. 보스/이벤트 후보 |

부여 근거는 (1) 실제 개체수와 접근성, (2) 크기와 힘, (3) 보호·감소 여부, (4) 낚시 난이도를 종합한 제 판단입니다.

## 난이도 산정 제안

원작도 시간, 계절, 날씨, 낚시 위치(배, 백사장, 갯바위)에 따라 어종이 달라지는 구조였습니다. 같은 구조를 쓰려면 어종마다 아래 점수를 계산해 맵과 레벨에 배치하면 됩니다.

```
크기점수 S=1, M=2, L=3, XL=4, XXL=5
난이도 D = 0.35*R + 0.30*P + 0.20*W + 0.15*크기점수   (범위 약 1.0 ~ 5.0)
```

| D 구간 | 용도 제안 |
|---|---|
| 1.0 ~ 2.0 | 입문 구간, 퀘스트 필수 잡어, 도감 채우기 |
| 2.0 ~ 3.0 | 일반 대상어, 중급 레벨 |
| 3.0 ~ 4.0 | 대물, 장비 요구, 시간·계절 제한 |
| 4.0 ~ 5.0 | 보스·전설 어종, 이벤트, 최상위 레벨 |

난이도 조정 아이디어:
- **HP(체력)**: 크기 등급에 비례하되 증가폭은 완만하게 (예: 체중^0.5)
- **텐션 변동폭 / 도주 속도**: P에 비례
- **입질 확률, 미끼 선호 적중 시 보너스**: W가 높을수록 입질 확률 낮추고 맞는 미끼 보너스를 크게
- **출현 가중치**: R이 높을수록 낮게, 시간대·계절·날씨·낚시 위치 조건을 AND로 걸기
- **퀘스트 연동**: R 4~5는 연속 퀘스트 보상 어종, 도감 완성 보상 대상으로 배치

## 이미지 링크 안내

- 모든 링크는 위키백과 종(species) 문서입니다. 영어판 문서가 기본이고, 문서 안의 대표 사진을 보면 됩니다.
- 학명으로 주소를 만들었기 때문에 일부 링크는 다른 이름으로 연결(리디렉션)되거나 문서가 없을 수 있습니다. 작업 환경에서 위키백과에 접속할 수 없어 **링크 작동 여부는 자동 검증하지 못했습니다.** 열리지 않는 링크는 영문명으로 위키백과나 구글 이미지에서 검색하세요.
