> ⚠️ 청풍명월 원작 데이터가 아니라, 낚시터의 실제 위치·환경을 기준으로 한 **실제 서식 어종 정리**입니다. (점수 기준은 `00_README_어종DB_가이드.md` 참고)

### 원작 어군 시스템과 연결 (앙코르와트, 푸켓, 센토사)
| 원작 어군 | 의미 | 제안 |
|---|---|---|
| 고기떼 | 입질이 빠르고 대상 어종 입질 확률 높음, 잡는 횟수 제한 | 떼 지어 다니는 소형어(은빛 바브, 잭, 청어류)로 구성 |
| 히든 | 고기떼를 모두 낚으면 출현 | 해당 풀의 R4~5 어종을 배정 |
| 포식자 | 지역 어군을 모두 사라지게 하고, 최고 레벨이 잡으면 복구 | 앙코르와트: 거대 가오리/메콩 메기, 푸켓: 돛새치·청새치, 센토사: GT/바라문디 |
