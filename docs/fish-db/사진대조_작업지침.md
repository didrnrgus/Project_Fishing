# 물고기 실물 사진 대조 — 작업 지침

어종마다 실물 사진을 찾아 우리 모델을 같은 각도로 렌더해 견주고, 설계 값을 고쳐 실물처럼 보이게 한다 ([09 문서 3-21장](../09-art-plan.md)). 진행 상황과 남은 어종은 [WORK-IN-PROGRESS](../WORK-IN-PROGRESS.md).

2026-10-29에 206종을 모두 한 번씩 대조했고, 2026-10-30에 머리 근접 사진("<학명> head close up")으로 눈·입·수염을 한 번 더 봤다 (09 문서 3-22장). 새 어종을 넣거나 한 어종을 다시 볼 때도 같은 순서로 한다 — 머리는 `<id>_head` 렌더로 견준다.

## 준비 (PC마다 한 번)

1. Blender 파이썬 `bpyenv`: [05 개발 가이드](../05-dev-guide.md) (`py -3.13 -m venv bpyenv` …)
2. 이미지 검색: [tools/image-search-mcp/README.md](../../tools/image-search-mcp/README.md) — venv 설치 + `claude mcp add` (세션을 새로 열면 `search_images` 도구가 보인다)

## 남은 어종 확인

```bash
bpyenv/Scripts/python -I tools/blender/photo_match_progress.py     # 설계 파일별 "고친 수/전체 남은: …" (기준 56c1da11 = 대조 시작 전)
```

상어·가오리·아귀·잉어·메기·두족류는 따로 다시 만들어서 대상이 아니다.

## 한 어종씩

1. 사진: `tools/image-search-mcp/.venv/Scripts/python tools/image-search-mcp/imgsearch.py "<학명 또는 영어 이름> side view" 6 <임시폴더>/ref.jpg` → Read로 본다. 맞는 종인지 확인한다 (살아 있거나 갓 잡은 고기의 옆모습이 좋다).
2. 렌더: `bpyenv/Scripts/python -I tools/blender/build_fish.py --preview --no-icons --only id1,id2 --out <임시폴더>` → `<id>_side/_head/_top/_three_q/_front_q.png`. 여러 장은 `tools/blender/preview_grid.py`로 한 장에 모아 본다.
3. 견줄 것 (잘 보이는 것부터): 옆 윤곽(몸 높이·가장 높은 곳·이마 경사·주둥이·입 위치와 크기·꼬리자루·꼬리 모양) → 지느러미(위치·길이·등지느러미 수·가시) → 눈 크기·위치 → 색·무늬. 비슷한 어종끼리 한눈에 구별되게 (감성돔·참돔·벵에돔, 우럭·볼락·쏨뱅이 …).
4. 설계 값만 고친다: `tools/blender/fish_species.py` 머리말의 값 설명, 다른 어종 예시 참고 (`hump`, `head_w`, `head_flat`, `lips`, `gape`, `jaw`, `blunt`, `mouth_h`, `keel`, 무늬 kind …). 어종마다 위에 한국어 주석으로 알아보는 특징을 적는다.
5. 1~3번 되풀이 (보통 어종당 1~3번).

## 규칙

- 공통 생성기(`build_fish.py`, `fish_tex.py`, `cephalopod.py`)·TEMPLATES·C#은 대조하면서 고치지 않는다. 없는 기능은 적어 두었다가 따로 넣는다.
- CPU 80% 아래: 에이전트는 동시에 3개까지, 에이전트마다 렌더는 한 번에 하나, 한 번에 8종 이하 (미리보기 렌더는 코어 1/6 스레드).
- 토큰: 어종마다 사진 모음 한 장, 렌더는 모아서 본다.
- 사진은 참고용 — 저장소·에셋에 넣지 않는다.
- 끝나면: 고친 어종을 한 번에 렌더해 빌드 오류가 없는지 확인 → 전체 빌드 `bpyenv/Scripts/python -I tools/blender/build_fish.py --sheet docs/images/32_fish_models.png` (약 1시간) → 테스트 → 문서 → 커밋.
