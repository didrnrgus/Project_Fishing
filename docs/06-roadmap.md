# 06. 로드맵

원작 한국 코스(1~25레벨)를 솔로로 다 즐길 수 있게 만드는 것이 다음 목표다. 해외 맵(동남아, 지중해, 나일강)은 그 다음이다.

## v0.1 (현재)
- [x] 한강 반포지구 맵 (6×4 격자, 서식지 4종, 다리·데크·수초·석축)
- [x] 캐스팅 / 예신·본신 / 챔질 / 두근두근
- [x] 1인칭 파이팅: 게이지 3종, 파이팅 레벨, 하이텐션, 카운터 콤보, 5m 랜딩
- [x] 어종 16종 + 잡동사니, 시간·날씨·서식지·미끼·어군 기반 입질
- [x] 캐릭터 체력, 요리, 김밥
- [x] 장비 10종, 미끼 6종, 내구도·수리, 판매
- [x] 도감 (단계별 해금), 살림망, 조합 퀘스트 8개
- [x] 낮/밤, 날씨, 가로등, 물안개
- [x] 저장/불러오기, 절차적 효과음
- [x] 밸런스 시뮬레이터, 자동 스크린샷

## v0.2 국내 맵 확장
- [ ] 맵 추상화 (`IMapDefinition`, [03-architecture.md](03-architecture.md#새-맵-추가-예-서천-앞바다) 참고)
- [ ] **서천 앞바다** (바다낚시, 조류, 갯바위/방파제) — 원작 국내 2번째 지역
- [ ] **제주** (원작 이벤트 지역)
- [ ] 레벨 라이선스로 맵 해금, 조합에서 이동
- [ ] 바다 어종: 우럭, 놀래미, 감성돔, 참돔, 돌돔, 농어, 광어, 다금바리, 돗돔 등

## v0.3 배
- [ ] 돛단배 → 고무보트 → 고속보트 → 크루저
- [ ] 연료(유지비), 배마다 능력치(속도, 연료통, 안정성)
- [ ] 먼 바다 칸은 배로만 갈 수 있게

## v0.4 솔로 콘텐츠
- [ ] **수족관**: 물고기·산호 배치, 배고픔, 먹이 주면 경험치
- [ ] **NPC 대회**: 원작 대회(마릿수/최장/길이 합계)를 AI 낚시꾼과 겨루는 솔로 버전, 계급 엠블럼
- [ ] 일일 퀘스트, 대물 퀘스트 (원작의 "자이언트 그루퍼" 같은 이벤트성 보스)
- [ ] 업적, 칭호
- [ ] 낚시법 추가: 루어(감기 액션), 플라이, 트롤링 (원작 개발자 인터뷰의 계획)
- [ ] 계절, 눈, 겨울 빙어낚시
