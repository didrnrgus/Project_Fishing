# 06. 로드맵

원작 한국 코스(1~25레벨)의 국내 낚시터 11곳과 원작 이벤트 지역 제주를 모두 열었고(2026-10-15), 원작 해외 거점 3곳(하롱베이 Lv.25·산토리니 Lv.28·나일강 하류 Lv.31)도 들어갔다: 한강·홍현·서천은 맵마다 따로 만든 월드, 나머지 12곳은 해안 맵 틀(`CoastMapDef`). 2026-10-20 원작 해외 거점 전체(동남아 12곳·지중해 4곳)를 열어 지금은 29곳, 어종 165종, 만렙 40. v0.5는 끝났고, v0.6은 플레이어 지적을 반영한 화면 퀄리티 작업이다(실사 나무·바위 에셋 연결이 남음).
