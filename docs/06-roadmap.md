# 06. 로드맵

원작 한국 코스(1~25레벨)를 솔로로 다 즐길 수 있게 만드는 것이 다음 목표다. 해외 맵(동남아, 지중해, 나일강)은 그 다음이다.

## v0.1
- [x] 한강 반포지구 맵 (6×4 격자, 서식지 4종, 다리·데크·수초·석축)
- [x] 캐스팅 / 예신·본신 / 챔질 / 두근두근
- [x] 1인칭 파이팅: 게이지 3종, 파이팅 레벨, 하이텐션, 카운터 콤보, 5m 랜딩
- [x] 어종 16종 + 잡동사니, 시간·날씨·서식지·미끼·어군 기반 입질
- [x] 캐릭터 체력, 요리, 김밥
- [x] 장비 10종, 미끼 6종, 내구도·수리, 판매
- [x] 도감 (단계별 해금), 살림망, 조합 퀘스트 8개
- [x] 낮/밤, 날씨, 가로등, 물안개
- [x] 저장/불러오기, 절차적 효과음
- [x] 밸런스 시뮬레이터, 자동 스크린샷

## v0.1.1 원작 영상 반영
- [x] 당겼다 미는 캐스팅, 큰 비거리 숫자, 하늘색 궤적
- [x] 누른 채 흔드는 챔질, 찌 클로즈업 BAD~PERFECT, 빨간 경보
- [x] 원작 파이팅 HUD (릴 손잡이 링, 거리 눈금자, 데미지 숫자, 빨간 꺾쇠, 원작 안내문, U로 끄기)
- [x] 질주 카운터 (속도선, 파란 화살표), 체력 높은 고기 5m 안 도망
- [x] 랜딩 찬스 연타 다이얼
- [x] RESULT 화면, 원작 단축키, 하단 메뉴 바, 이름표, 한강 소품

## v0.1.2 참고 영상 다듬기 (현재)
- [x] 사람: Quaternius CC0 캐릭터 + 옷 셰이더 + 머리·모자·이름표/칭호, Playables 애니메이션
- [x] NPC: 뗏목·둔치 낚시꾼, 낚시점 김사장
- [x] 파이팅 물고기 3D 모델 (Fish1~3 + 어종 색)
- [x] 물결 셰이더(버텍스 파도 + 노멀맵 2장, 하늘 반사), 해·달·별, 날씨별 구름
- [x] 대기실(한국 낚시 조합), 낚시터 목록(한국 지도, 채널 CH.1~5, 빠른입장)
- [x] 지역 지도(M), 장력 위험 빨간 테두리
- [x] 큰 어군/작은 어군, 작은 고기로 생미끼 만들기
- [x] 드래그 장력(반대쪽으로 계속 당기면 끊김, 물고기 쪽으로 끌면 늦춤), 장력 바 % · 한계 표시
- [x] Space 점프, 초상화를 실시간 캐릭터 카메라로, 1인칭을 원작처럼(왼쪽 아래 낚싯대, 큰 릴, 장갑 낀 손)
- [x] 뽑기대(마디 펼치기, 장비별 모양), 장비별 스피닝 릴(감기·드랙 회전), 릴·드랙·버팀·카운터 소리
- [ ] 밤 강물에 다리·도시 불빛이 길게 비치는 반사
- [ ] RESULT 화면에도 3D 물고기
