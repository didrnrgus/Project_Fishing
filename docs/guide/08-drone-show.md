# 탄천 드론쇼 장면 바꾸기 (빌드한 뒤에도)

탄천 맵의 밤하늘(탄천종합운동장 위)에는 드론 3,000대가 그림을 그린다. 장면 하나를 10초 보여 주고, 5초 동안 드론이 날아가 다음 장면이 된다.
장면은 **점 파일(.json)** 하나가 한 장이다. 게임을 다시 빌드하지 않고 **파일만 넣거나 지우면** 된다.

> 같은 설명서가 게임 폴더 `ProjectFishing_Data\StreamingAssets\DroneShow\읽어주세요.txt`에도 들어 있다.

## 폴더 두 곳

| | 위치 | 특징 |
|---|---|---|
| **[A] 내 폴더** | `문서\짭풍명월\DroneShow` | 내가 넣은 장면과 내 설정. OneDrive로 문서를 옮긴 PC는 `OneDrive\문서` 아래 (예: `C:\Users\<이름>\OneDrive\문서\짭풍명월\DroneShow`). 없으면 만든다. 게임을 지우거나 새 버전을 깔아도 남는다 |
| **[B] 게임 폴더** | `게임 설치 폴더\ProjectFishing_Data\StreamingAssets\DroneShow` | 기본 장면 `title.json`(게임 타이틀 「청풍명월」 붓글씨와 금빛 영문)과 기본 설정 `droneshow.json`. 새 버전을 깔면 원래대로 돌아간다 |

- 기본 순서: 타이틀 → [A]의 장면을 **파일 이름 순서**로 (이름 속 숫자는 수 크기로: `points_2` → `points_10`). 끝나면 처음부터 다시.
- 탄천 맵에 **들어갈 때** 읽는다. 파일을 바꿨으면 다른 맵에 갔다 오거나 게임을 다시 켠다.
- [A]가 없거나 비어 있으면 타이틀 장면만 나온다 (같은 그림을 다시 그린다).
- 장면 빼기: 그 `.json` 파일을 지운다. 번호가 비어도 괜찮다.

## 순서·폴더·시간 바꾸기 (`droneshow.json`)

[A] 내 폴더에 `droneshow.json`을 만들고 **바꾸고 싶은 줄만** 적는다. 적지 않은 항목은 [B]의 기본 설정을 그대로 쓴다.

```json
{
    "folders": ["{documents}", "D:\\내그림\\드론"],
    "scenes": ["points_3", "title", "points_2"],
    "holdSeconds": 8,
    "moveSeconds": 4
}
```

| 항목 | 기본 | 뜻 |
|---|---|---|
| `folders` | `["{game}", "{documents}"]` | 장면을 찾을 폴더, 차례대로 (폴더 안은 이름 순서). `{game}` = [B] 게임 폴더(타이틀), `{documents}` = [A] 내 폴더, 그 밖엔 전체 경로 (`\\` 두 번, `%USERPROFILE%` 같은 환경 변수도). **타이틀을 빼려면 `{game}`을 뺀다** |
| `scenes` | `[]` (전부) | 적으면 이 장면들만 이 순서로. 파일 이름(`.json`은 빼도 된다)을 `folders`에서 찾는다. 전체 경로도 된다 |
| `holdSeconds` | 10 | 장면을 보여 주는 시간 (초) |
| `moveSeconds` | 5 | 다음 장면으로 날아가는 시간 (초). 드론들은 처음 1초(5초 기준, 짧으면 그만큼 줄어든다) 동안 왼쪽부터 차례로 출발한다 |

쉼표·따옴표가 틀리면 그 파일은 무시된다 (게임 로그에 `[DroneShow]`로 남는다). 적은 장면 파일이 없어도 로그에 남는다.

## 점 파일 모양

```json
[
  [0.4213, 0.1875, 255, 240, 230],
  [0.4301, 0.1902, 250, 238, 228, 1]
]
```

- 한 줄이 드론 한 대: `x, y`(0~1, 그림의 긴 변 = 1, `y`는 아래쪽이 +) · `r, g, b`(0~255 불빛 색).
- 여섯째 값(없어도 된다)은 깜빡임: 1 반짝 · 2 전광판처럼 달리는 불빛 · 3 깜빡 · 4 일렁임 · 5 번쩍.
- 3,000점까지 쓴다 (넘으면 잘린다). 적으면 남는 드론은 꺼진 채 기다린다.
- 크기·위치는 게임이 맞춘다: 점들의 가운데를 판 가운데로, 가로 폭 또는 세로 높이에 맞춰 키운다. 세로로 긴 그림도 한눈에 들어온다.

## 그림 → 점 파일 만들기

저장소의 `tools/drone/`에 도구가 있다 (Python 3.8 이상, `pip install pillow numpy scikit-learn scipy`).

```
python tools/drone/scene.py 내그림.png                 # 다음 번호(points_N.json)로 내 장면 폴더에 바로 넣는다
python tools/drone/scene.py 내그림.png --name points_2 # 2번 장면을 이걸로 바꾼다
python tools/drone/scene.py 내그림.png --cutout        # 배경이 복잡한 그림 (풍경·게임 화면): AI로 피사체만 딴다
```

- 점 뽑기는 `drone_points.py`: 그림 가장자리 색으로 배경을 알아서 지우고(검정 = 드론 끔), 검은 부분도 끄고, 남은 곳을 3,000점으로 고르게 나눠 그 자리 평균색을 매긴다.
- 실행하면 꺼지는 곳을 검게 칠한 미리보기(`%TEMP%\drone_preview_<이름>.png`)가 나온다. 배경이 남으면 `--tol 70`, 그림까지 지워지면 `--tol 30`, 선이 많은 그림은 `--edge-boost 3`.
- `--cutout`은 `pip install "rembg[cpu]"`가 필요하다. 처음 쓸 때 모델(약 170MB)을 받는다.
- 단색·검정 배경 그림이 가장 깔끔하다. 피사체가 그림 가장자리에 닿아 있으면 그 부분이 배경으로 지워질 수 있다.
- 기본 타이틀 장면은 `python tools/drone/title_scene.py`로 인트로 타이틀 그림에서 다시 뽑는다 (붓글씨·영문만, 붉은 낙관 「짭」은 뺐다).

## 저작권

남의 그림(만화·게임 캐릭터 등)으로 만든 점 파일은 **내 PC에서만** 쓴다. 이 저장소는 공개 저장소라 그런 점 파일과 그 스크린샷은 넣지 않는다.
