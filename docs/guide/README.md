## 누적 경험치

다음 레벨까지 필요한 경험치는 `100 × 현재 레벨^1.5`다.

| 도달 레벨 | 누적 경험치 |
|---|---|
| 5 | 1,703 |
| 10 | 11,106 |
| 15 | 31,998 |
| 20 | 67,135 |
| 25 | 118,809 |
| 31 | 205,461 |
| 40 | 392,197 |

경험치 = `어종 경험치 × √(길이 ÷ 최소 길이)`. 대물이면 ×2, **방생하면 30%를 더 준다**.
레벨이 오를수록 이야기 퀘스트 보상(수천~1만5천)이 경험치의 큰 몫을 차지한다.

## 모든 구간에 통하는 기본기

### 1. 캐스팅: 당기고, 빠르게 민다
- 왼쪽 버튼을 누른 채 **아래로 당긴 양**이 위력의 바탕이고, 놓기 직전 **0.15초 동안 위로 민 양**이 비거리를 정한다.
- 천천히 밀면 아무리 많이 당겨도 짧게 날아간다. "짧고 빠르게 휙"이 요령이다.
- 조준 링이 빨갛게 바뀌면 궤적에 등대·나무·사람 같은 장애물이 있다는 뜻이다. 방향을 틀어서 다시 던진다.

### 2. 챔질: 찌가 다 잠겼을 때 흔든다
- 예신(찌가 살짝 깔짝)에 흔들면 **헛챔질**이다. 미끼를 잃을 수 있고 다시 기다려야 한다.
- 본신(머리 위 빨간 `!`)이 오면 찌가 1.1초에 걸쳐 잠긴다. **끝까지 잠긴 순간(97% 이상)에 흔들면 PERFECT**.
- PERFECT는 바늘 걸림 100에서 시작하고 **카운터 콤보 1개를 덤으로** 받는다.
- 다 잠긴 뒤 0.6초가 지나면 고기가 미끼만 따먹고 간다.

| 찌 잠김 | 등급 |
|---|---|
| 20% 미만 | BAD (헛챔질) |
| 45% 미만 | SO SO |
| 70% 미만 | GOOD |
| 97% 미만 | GREAT |
| 97% 이상 | **PERFECT** |

### 3. 파이팅: 주황 구간에 머문다
- 장력 바 **0.6~0.9(주황, 하이텐션)** 에서 데미지가 1.3배로 가장 효율이 좋다. 빨강(0.9 이상)은 1.6배지만 곧 끊어진다.
- 장력 1.0을 넘은 채 **0.7초**를 버티면 줄이 끊어진다. 위험하면 바로 오른쪽 버튼(풀기)을 누른다.
- 줄이 너무 느슨하면(장력 0.1 미만) 바늘이 빠진다. 감기를 완전히 멈추지 않는다.
- **낚싯대는 물고기 반대쪽으로** 겨눈다. 반대쪽으로 버틸수록 데미지가 커진다.
- 마우스를 물고기 반대쪽으로 계속 끌면 장력이 쌓인다. 너무 팽팽하면 **물고기 쪽으로 살짝 끌어서** 늦춘다.

### 4. 5m 규칙과 랜딩
- 체력(HP)이 20% 넘게 남은 고기를 **5m 안으로 끌어오면 놀라서 도망간다**(질주하며 9m/s로 멀어진다).
- HP를 먼저 깎고, HP 20% 이하가 된 뒤에 끌어온다. 그러면 **랜딩 찬스**가 열린다.
- 랜딩은 Space나 왼쪽 버튼을 **초당 4~5번 이상** 연타한다. 오래 버틸수록 고기가 지쳐서(12초에 걸쳐 버티는 힘 ×0.25) 끝내 올라온다.

### 5. 카운터
- 물고기가 질주하거나 화면 한쪽 끝에 몰리면 **파란 화살표**가 뜬다.
- 화살표 방향(물고기 반대쪽)으로 **0.15초 안에 크게 휙**(약 120px) 튼다.
- 맞히면 최대 HP의 7%(+콤보마다 2%)를 한 번에 깎고 장력도 ×0.6으로 내려간다. 콤보는 5까지 쌓인다.

### 6. 포커싱 (Q)
- 8초 동안 장력이 천천히 변하고 데미지가 1.5배(카운터 1.3배)가 된다. 실제 시간 20분에 한 번 쓴다.
- **대물의 첫 질주를 버틸 때**나 장력이 자꾸 튈 때 쓴다.

### 7. 체력
- 체력이 20% 이하면 데미지·랜딩 연타 ×0.45, 5% 이하면 ×0.15로 떨어진다. 대물 직전에는 꼭 채운다.
- 김밥(+40 즉시), 컵라면(+20 즉시), 어묵·믹스커피(분당 회복), 바다 도시락(즉시+분당). 살림망 고기를 요리해도 된다.
- 레벨이 오르면 체력이 가득 찬다.

### 8. 입질을 빨리 받는 법

| 조건 | 효과 |
|---|---|
| 서식지가 맞음 | 아니면 입질 확률 ×0.12 |
| 미끼가 맞음 | 아니면 ×0.15 |
| 활동 시간대 | 아니면 ×0.3 |
| 선호 날씨 | ×1.3 |
| 제철 | ×1.6 (철이 아니면 ×0.35) |
| 큰 어군 안 | 그 어군 어종 ×4, 대기 시간 ×0.5 |
| 하얀 소용돌이 한가운데 | 대기 시간 ×0.7 더 |
| 들물(서해 물때) | 대기 시간 ×0.75 (만조·간조엔 ×1.25) |

- **도감(P)** 에서 같은 어종을 3마리 낚으면 선호 미끼, 5마리면 활동 시간·서식지가 공개된다.
- **조합 연락관에게 조황을 물으면** 지금 활발한 어군의 칸·미끼를 알려 준다.
- 하얀 소용돌이 = 어군, **금빛** = 히든 어군(입질 ×6), **붉은색** = 포식자 어군(그 맵에서 가장 센 고기). 포식자를 낚으면 흩어졌던 어군이 바로 다시 모인다.

### 9. 계절

한 달 = 게임 7일, 하루 = 실제 24분. 1일째가 4월 1일이다.

| 계절 | 게임 날짜 | 제철 대표 |
|---|---|---|
| 봄 | 1~14일, 78~84일 | 붕어·잉어, 주꾸미, 갑오징어, 참돔 |
| 여름 | 15~35일 | 메기, 가물치, 뱀장어, 민어, 농어 |
| 가을 | 36~56일 | 전어, 고등어, 감성돔, 방어 |
| 겨울 | 57~77일 | 빙어(한강 얼음 구멍), 대구, 명태 |

84일마다 한 바퀴 돈다.

### 10. 꾸준히 챙길 것
- **출석 체크**: 실제 날짜로 하루 한 번. 7일째 고속정 **블랙스피어**.
- **일일 의뢰**: 게임 하루마다 3개. 골드·경험치가 쏠쏠하다.
- **조합 낚시 대회**: 매일 게임 09~15시. 1위 거거 낚시대, 2위 나팔고둥 릴.
- **빙고**: 3줄이면 나팔고둥 릴(첫 판), 황금거거 낚싯대(둘째 판).
- **대물 도전**: 어종마다 대물 기준을 처음 넘기면 경험치 ×2 + 소라고동 3.
