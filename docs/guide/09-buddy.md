# 낚시 친구 윤슬

낚시터에서 늘 내 오른쪽에서 따라다니는 친구다. 걸으면 같이 걷고, 뛰면 같이 뛰고, 낚시하면 옆에 서서 물을 본다.
고기를 낚거나 놓치면, 레벨이 오르면, 이야기 퀘스트를 끝내면, 처음 온 낚시터에 들어서면 한마디씩 한다.

## 길 안내

말로만 알려 주지 않고 **직접 앞장서 데려간다**. AI 없이 게임 데이터로 바로 움직여서 Ollama가 꺼져 있어도 된다.

| 퀘스트 NPC에게 | 도착 | 낚시 포인트 | 배 같이 타기 |
|---|---|---|---|
| ![앞장서기](../images/30g_buddy_lead.png) | ![도착](../images/30h_buddy_arrive.png) | ![포인트](../images/30i_buddy_point.png) | ![배](../images/30j_buddy_boat.png) |

- **퀘스트**: "내 퀘스트 좀 알고 싶어", "누구한테 가야 해? 데려다줘" → 이 낚시터에서 가장 급한 NPC(보고할 사람 > 이야기 퀘스트 > 받을 퀘스트 > 진행 중)에게 "따라와!" 하고 걸어간다. 닿으면 "여기야! F 눌러서 말 걸어 봐". 그 사람이 대기실·다른 낚시터에 있으면 어디로 가야 하는지 말해 준다.
- **사람·가게**: "박주임 어디 있어?", "낚시점 데려가 줘" → 그 사람에게.
- **낚시 포인트**: "붕어 어디서 잡아?" → 그 고기가 사는 칸(수초·여울·암초…)에서 가장 가까운 물가로 데려가 던질 물을 **손으로 가리킨다**. 물가에서 낚싯대가 안 닿는 곳(먼바다·섬 건너)이면 배 띄울 물가로 데려가 "여기서 배를 타야 해! B 눌러서 배 꺼내" — 다른 낚시터 고기면 어디 사는지 말로.
- 뒤처지면 서서 돌아보며 가리키고 부른다. 반대로 가면 "아니야, 저기야!" 하고 가리킨다.
- **배**: 배에 타면 윤슬도 같이 탄다(내가 운전석에 앉으면 뱃머리, 뱃머리에 서면 운전석). 포인트로 가는 중이면 뱃머리에서 가리키고, 닿으면 "여기야, 여기서 던져 봐".

## 대화하기

| 키 | 하는 일 |
|---|---|
| **Enter** | 대화창 열기 → 입력칸에 쓰고 Enter로 보내기 |
| 빈칸에서 Enter / **Esc** | 대화창 닫기 |

- 대화창은 게임을 막지 않는다. 열어 둔 채 걷고 낚시해도 된다. 입력칸에 글을 쓰는 동안만 이동과 단축키가 멈춘다.
- 내가 보낸 말은 내 머리 위에(노란 글), 윤슬의 대답은 윤슬 머리 위에 말풍선으로 뜬다. 말풍선 아래 꼬리가 말한 사람을 가리키고, 둘이 붙어 서 있으면 내 말이 위·대답이 아래로 쌓여 대화처럼 읽힌다.
- 대답은 다 만들어질 때까지 기다리지 않고 **나오는 대로 이어서** 보인다(오른쪽 위 "말하는 중…"). 기본 모델로 보통 **1~2초**.
- 무엇이든 물어봐도 된다: "지금 뭐 하면 좋아?", "홍현 앞바다는 몇 레벨부터야?", "줄이 자꾸 끊겨" 같은 게임 얘기는 물론, **게임 밖 질문**도 — "이 PC 사양 어때?"(이 PC의 CPU·RAM·그래픽카드를 읽어 대답), "이 게임 물은 어떻게 만들었어?"(개발 문서에서 찾아 설명), 공부·개발·일상 얘기.
- 대화창에는 대답 전체(8문장까지), 말풍선에는 4문장까지 보인다.
- 질문을 보내면 게임이 먼저 질문에 나온 물고기·낚시터 정보, 레벨·퀘스트 질문이면 그 표, 이 가이드에서 질문 낱말이 든 줄을 찾아 질문에 붙여 준다. 윤슬은 그 사실로 대답한다(작은 모델이 지어내지 않게).
- 도구를 쓸 수 있는 모델(qwen3)은 모자라면 가이드·도감을 더 찾아본다. 말풍선에 "가이드 펼쳐 보는 중…", "도감 찾아보는 중…"이 뜨는 동안이다.

## 윤슬이 대답하게 하려면: Ollama (무료)

대화는 **내 PC에서 도는 AI**로 한다. 돈이 들지 않고, 로그인도 없고, 인터넷이 끊겨도 되고, 대화가 PC 밖으로 나가지 않는다.
Ollama가 없어도 윤슬은 따라다니고 정해진 반응 말은 한다. 자유롭게 물어보려면 Ollama가 필요하다.

1. 대화창의 **[설치 안내 (브라우저)]** 를 누르면 기본 브라우저에서 [ollama.com/download](https://ollama.com/download)가 열린다. 받아서 설치한다.
2. 게임에서 대화창을 열면(또는 **[Ollama 켜기]**) 게임이 Ollama를 알아서 켠다. 켜 둘 필요가 없다.
3. 처음이면 오른쪽 위에 "모델 없음"이 뜬다. **[모델 받기 (3.4GB)]** 를 누르면 게임 안에서 받는다. 진행률이 버튼과 오른쪽 위에 보이고, 받는 동안에도 낚시는 그대로 할 수 있다.
4. 다 받으면 윤슬이 "다 받았다!"라고 말하고 초록 점 "이 PC의 AI 연결됨"이 뜬다.

- 명령 창이 편하면 `ollama pull gemma3:4b`로 받아도 같다.
- 받다가 게임을 꺼도 받은 만큼은 남는다. 다음에 [모델 받기]를 누르면 이어 받는다.
- 게임이 켠 Ollama는 게임을 끌 때 같이 꺼진다. 직접 켠 Ollama(트레이의 라마 아이콘)는 건드리지 않는다. 트레이에서 **Quit Ollama**를 누르면 꺼진다.
- **[모델: …]** 버튼을 누르면 깔린 모델끼리 돌아가며 바꾼다 (고른 모델은 기억한다).
- 대화창을 열면 그때 모델을 그래픽카드에 올린다(처음엔 몇 초~30초). 질문을 쓰는 동안 끝난다. 대화하지 않으면 그래픽 메모리를 쓰지 않는다.
- 모델 비교 (RTX 5060 8GB, 게임과 Unity 에디터가 같이 돌 때, 같은 질문):

| 모델 | 받기 | 대답 | 메모 |
|---|---|---|---|
| **`gemma3:4b`** (기본) | 3.3GB | **약 1초** | 한국어 반말이 가장 자연스럽고 붙여 준 자료를 잘 읽는다. 도구는 못 쓴다(붙여 준 자료로만) |
| `qwen3:4b-instruct` | 2.5GB | 약 1초 | 도구를 쓴다. 대신 "덜 끊긴다"를 "끊기 쉽다"로 읽는 식으로 자주 틀리고 존댓말이 섞인다 |
| `qwen3:8b` | 5.2GB | 10~60초 | 가장 똑똑하지만 6GB를 써서 8GB 카드에서는 게임과 나눠 쓰다 넘친다. 12GB 이상 카드라면 쓸 만하다 |
| `qwen3:4b` | 2.5GB | 15~30초 | 대답 전에 영어로 길게 혼자 생각한다. 비추천 |

- 작은 모델이 가끔 붙이는 것(존댓말 끝 "~요", 그림 문자, 자료 되읊기, 파일 이름)은 게임이 지우고, 말풍선에 들어가게 4문장까지만 보인다.

| 대화창 오른쪽 위 | 뜻 |
|---|---|
| 초록 ● 이 PC의 AI 연결됨 | 대화할 수 있다 |
| 파랑 ● Ollama 켜는 중… | 게임이 켜는 중 (몇 초) |
| 빨강 ● Ollama 꺼짐 — [Ollama 켜기] | 깔려 있는데 꺼졌다. [Ollama 켜기]를 누른다 |
| 빨강 ● Ollama 없음 | [설치 안내]로 설치한다 |
| 주황 ● 모델 없음 | [모델 받기]를 누른다 |
| 파랑 ● 모델 받는 중 1.2/3.3GB (36%) | 받는 중 |

## 윤슬 모습 바꾸기

윤슬의 모델은 `characters.json`의 `npc` 목록에서 이름 `"윤슬"`로 정한다 ([캐릭터 바꾸기](07-characters.md)). 기본은 `AvatarSample_F.vrm`.

```json
"npc": [
    { "name": "윤슬", "file": "내가_만든_캐릭터.vrm" }
]
```

## 바깥 AI에 게임 지식 연결하기 (MCP, 고급)

게임은 윤슬이 쓰는 "게임 지식 도구"를 **MCP 서버**로도 연다. Claude Code 같은 MCP를 쓰는 AI가 실행 중인 게임에 붙어 가이드 문서와 내 상황을 읽을 수 있다.

- 빌드한 게임은 실행 옵션에 `-mcp`를 붙여야 켜진다 (에디터에서는 늘 켜짐). 주소는 `http://127.0.0.1:8770/mcp`이고, 이 PC 안에서만 받는다.
- Claude Code에 붙이기: `claude mcp add --transport http project-fishing http://127.0.0.1:8770/mcp`
- 도구: `game_state`(지금 상황), `list_guides`·`read_guide`·`search_guides`(이 가이드), `fish_info`(어종), `map_info`(낚시터), `quest_info`(퀘스트), `system_info`(이 PC 사양), `search_dev_docs`·`read_dev_doc`(개발 문서)
