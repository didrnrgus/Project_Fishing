# 낚시 친구 윤슬

낚시터에서 늘 내 오른쪽에서 따라다니는 친구다. 걸으면 같이 걷고, 뛰면 같이 뛰고, 낚시하면 옆에 서서 물을 본다.
고기를 낚거나 놓치면, 레벨이 오르면, 이야기 퀘스트를 끝내면, 처음 온 낚시터에 들어서면 한마디씩 한다.

## 대화하기

| 키 | 하는 일 |
|---|---|
| **Enter** | 대화창 열기 → 입력칸에 쓰고 Enter로 보내기 |
| 빈칸에서 Enter / **Esc** | 대화창 닫기 |

- 대화창은 게임을 막지 않는다. 열어 둔 채 걷고 낚시해도 된다. 입력칸에 글을 쓰는 동안만 이동과 단축키가 멈춘다.
- 대답은 대화창과 윤슬 머리 위 말풍선에 나온다. 다 만들어질 때까지 기다리지 않고 **나오는 대로 이어서** 보인다(오른쪽 위 "말하는 중…").
- 무엇이든 물어봐도 된다: "붕어는 어디서 잡아?", "지금 뭐 하면 좋아?", "홍현 앞바다는 몇 레벨부터야?", "줄이 자꾸 끊겨", "다음 퀘스트 어떻게 해?"
- 윤슬은 대답하기 전에 이 가이드 문서와 게임 데이터(어종·낚시터·퀘스트)와 내 상황(레벨·장비·있는 곳·시간·날씨)을 직접 찾아본다. 말풍선에 "가이드 펼쳐 보는 중…", "도감 찾아보는 중…"이 뜨는 동안이다.

## 윤슬이 대답하게 하려면: Ollama (무료)

대화는 **내 PC에서 도는 AI**로 한다. 돈이 들지 않고, 로그인도 없고, 인터넷이 끊겨도 되고, 대화가 PC 밖으로 나가지 않는다.
Ollama가 없어도 윤슬은 따라다니고 정해진 반응 말은 한다. 자유롭게 물어보려면 Ollama가 필요하다.

1. 대화창의 **[설치 안내 (브라우저)]** 를 누르면 기본 브라우저에서 [ollama.com/download](https://ollama.com/download)가 열린다. 받아서 설치한다.
2. 명령 창(PowerShell)에서 모델을 한 번 받는다 (약 5GB):
   ```
   ollama pull qwen3:8b
   ```
3. 게임에서 대화창의 **[다시 연결]** 을 누른다. 오른쪽 위에 초록 점과 "이 PC의 AI 연결됨"이 뜨면 된다.

- Ollama 창은 닫아도 된다. 작업 표시줄 트레이(라마 아이콘)에서 계속 돈다. 트레이에서 **Quit Ollama**를 누르면 꺼진다.
- **[모델: …]** 버튼을 누르면 깔린 모델끼리 돌아가며 바꾼다 (고른 모델은 기억한다).
- 대화창을 열면 그때 모델을 그래픽카드에 올린다(처음엔 30초쯤). 질문을 쓰는 동안 끝난다. 대화하지 않으면 그래픽 메모리를 쓰지 않는다.
- 대답 시간은 그래픽카드 메모리에 달렸다. 8b 모델은 약 6GB를 쓰는데, 8GB 카드에서 게임과 다른 프로그램(다른 Unity 에디터 등)이 같이 돌면 메모리가 모자라 **20~50초**까지 걸린다. 12GB 이상이거나 다른 프로그램을 닫으면 훨씬 빠르다.
- `qwen3:4b`는 대답 전에 혼자 길게 생각해서 오히려 느리고, `qwen3:4b-instruct`는 1초 안에 대답하지만 없는 사실을 지어내는 일이 잦다. 그래서 기본은 8b다.

| 대화창 오른쪽 위 | 뜻 |
|---|---|
| 초록 ● 이 PC의 AI 연결됨 | 대화할 수 있다 |
| 빨강 ● Ollama 꺼짐 | Ollama를 켜고 [다시 연결] |
| 주황 ● 모델 없음 | `ollama pull qwen3:8b` 후 [다시 연결] |

## 윤슬 모습 바꾸기

윤슬의 모델은 `characters.json`의 `npc` 목록에서 이름 `"윤슬"`로 정한다 ([캐릭터 바꾸기](07-characters.md)). 기본은 `AvatarSample_F.vrm`.

```json
"npc": [
    { "name": "윤슬", "file": "내가_만든_캐릭터.vrm" }
]
```

## 바깥 AI에 게임 지식 연결하기 (MCP, 고급)

게임은 윤슬이 쓰는 "게임 지식 도구"를 **MCP 서버**로도 연다. Claude Code 같은 MCP를 쓰는 AI가 실행 중인 게임에 붙어 가이드 문서와 내 상황을 읽을 수 있다.

- 빌드한 게임은 실행 옵션에 `-mcp`를 붙여야 켜진다 (에디터에서는 늘 켜짐). 주소는 `http://127.0.0.1:8770/mcp`이고, 이 PC 안에서만 받는다.
- Claude Code에 붙이기: `claude mcp add --transport http project-fishing http://127.0.0.1:8770/mcp`
- 도구: `game_state`(지금 상황), `list_guides`·`read_guide`·`search_guides`(이 가이드), `fish_info`(어종), `map_info`(낚시터), `quest_info`(퀘스트)
