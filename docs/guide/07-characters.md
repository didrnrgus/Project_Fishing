# 캐릭터 바꾸기 (빌드한 뒤에도)

게임 속 사람은 모두 **VRM 파일**이다. 내 캐릭터, 낚시점 사장, 조합 연락관, 낚시꾼 NPC, 배 선장이 모두 여기에 들어간다.
VRM은 [VRoid Studio](https://vroid.com/studio)(무료) 같은 프로그램으로 만드는 캐릭터 파일이고, VRM 0.x와 1.0 모두 읽는다.
게임을 다시 빌드하지 않고 **파일만 넣거나 바꾸면** 된다.

> 같은 설명서가 게임 폴더 `ProjectFishing_Data\StreamingAssets\Characters\읽어주세요.txt`에도 들어 있다.

## 폴더 세 곳

| | 위치 | 특징 |
|---|---|---|
| **[A] 내 폴더** | `문서\짭풍명월\Characters` | 캐릭터 창(C) → [캐릭터 모델] → **[폴더 열기]**로 열린다. 게임을 지우거나 새 버전을 깔아도 남는다. OneDrive로 문서를 옮긴 PC는 `OneDrive\문서` 아래 |
| **[B] 게임 폴더** | `게임 설치 폴더\ProjectFishing_Data\StreamingAssets\Characters` | 게임과 함께 온 기본 캐릭터 11개, `characters.json`, `읽어주세요.txt`. 새 버전을 깔면 원래대로 돌아간다 |
| **[C] 추가 캐릭터** | `게임 설치 폴더\Characters` (ProjectFishing.exe 옆) | 빌드에 넣지 않는 캐릭터(VRoid Hub 등에서 받은 남의 모델). **`파일.vrm`과 같은 이름의 정보 `파일.json`이 함께 있는 것만** 쓴다. 캐릭터 창 [캐릭터 모델] 위 **[열기]** |

같은 이름의 파일이 여러 곳에 있으면 **[A] → [C] → [B]** 순으로 이긴다. 그래서 바꿀 때는 [A]를 쓰는 게 좋다.

### [C] 추가 캐릭터 정보 파일

`Rosi.vrm` 옆에 `Rosi.json`:

```json
{
    "name": "로지",
    "gender": "female",
    "author": "skye_cloudx",
    "url": "https://hub.vroid.com/characters/8388903670414959937/models/3821787996741928815",
    "license": "VRoid Hub 이용 조건: 재배포·개조·상업 이용 허락",
    "credit": false
}
```

| 항목 | 뜻 |
|---|---|
| `name` | 게임에 보일 이름 (비우면 VRM 안의 이름, 일본어는 글꼴에 없어 빠질 수 있다) |
| `gender` | `"female"` / `"male"` — 적으면 그 성별 **NPC 후보에 저절로 들어간다** (`characters.json`의 `npcFemale`/`npcMale`에 더해서) |
| `author`, `url`, `license` | 만든 사람·받은 곳·이용 조건 (캐릭터 창에 만든 사람이 나온다) |
| `credit` | `true`면 캐릭터 창에 "만든 사람 표기가 필요해요" |
| `brightness` | 밝기 배수 (0.2~1.5, 적지 않으면 `characters.json`의 `brightness` 또는 1) |

정보 파일이 없는 `.vrm`은 목록에 안 나오고 캐릭터 창에 노란 글씨로 알려 준다. 게임 폴더를 통째로 남에게 줄 때는 [C]의 모델마다 **재배포 허락**을 확인할 것 (VRoid Hub 모델 페이지의 이용 조건).
에디터에서 실행하면 `Builds\Windows\Characters`를 읽는다 (저장소에는 안 올라간다, `.gitignore`의 `Builds/`).

## 1. 내 캐릭터 바꾸기 (가장 쉬움)

1. 만든 `.vrm` 파일을 [A] 내 폴더에 넣는다.
2. 게임에서 **C** → **[캐릭터 모델]** 탭 → **[새로고침]**.
3. 목록에서 그 캐릭터의 **[고르기]** → 필드·대기실·초상화가 바로 바뀐다.
4. 아래 **[남자]/[여자]**: 고른 VRM이면 걸음걸이(서 있는 자세·걷는 동작), [기본 캐릭터]면 남/녀 기본 모델.

게임과 함께 온 11개도 목록에 `기본 제공`으로 나와서 그대로 고를 수 있다.

## 2. 기본 캐릭터·NPC 바꾸기 (`characters.json`)

누구에게 어떤 파일을 입힐지는 `characters.json`에 적혀 있다. 메모장으로 연다.

| 항목 | 뜻 |
|---|---|
| `playerMale` / `playerFemale` | 기본 캐릭터 (남자 / 여자) |
| `npcMale` / `npcFemale` | 남자 / 여자 NPC가 고를 모델 목록. NPC마다 **이름으로** 하나를 골라 늘 같은 모델을 입는다. 같은 모델이라도 머리·옷 색과 키가 사람마다 다르다 |
| `npc` | 특정 NPC에게 정해서 입히기. `name`은 머리 위 이름표 그대로 (예: `"홍현 낚시점 최사장"`). 이렇게 정한 사람은 색을 바꾸지 않고 모델 그대로 나온다 |

### 방법 ① 내 폴더에 `characters.json` 만들기 (권장)

[A] 내 폴더에 `characters.json`을 새로 만들고 **바꾸고 싶은 줄만** 적는다. 적지 않은 항목은 [B] 게임 폴더 설정을 그대로 쓴다.

```json
{
    "playerMale": "MyHero.vrm",
    "npc": [
        { "name": "홍현 낚시점 최사장", "file": "Boss.vrm" }
    ]
}
```

- `npc`는 [B]의 목록과 **합쳐진다**. 같은 이름이 있으면 내 폴더 것이 이긴다.
- `npcMale`·`npcFemale`을 적으면 그 목록은 **통째로** 내 것으로 바뀐다.

### 방법 ② 같은 이름으로 덮기

[B]에 있는 파일과 **똑같은 이름**(예: `HairSample_Male.vrm`)으로 [A]에 넣으면 그 파일이 대신 쓰인다. `characters.json`은 고치지 않아도 된다.

### 방법 ③ 게임 폴더를 직접 고치기

[B]의 `characters.json`과 `.vrm`을 직접 바꿔도 된다. 새 버전을 깔면 원래대로 돌아간다.

파일 이름에 `.vrm`은 붙여도 되고 빼도 된다. 적은 파일을 못 찾거나 JSON이 깨지면(쉼표·따옴표 빠짐) 캐릭터 창 [캐릭터 모델] 탭 맨 위에 **노란 글씨**로 알려 준다.

## 옷 갈아입기

- 대기실 **[옷 바꾸기]** 또는 캐릭터 창 [캐릭터 모델] 탭의 옷 줄 **[랜덤]**: 가진 VRM 중 하나의 옷을 무작위로 입는다. 얼굴·머리는 그대로다.
- **[기본]**: `characters.json`에 정한 옷 (주인공은 흰 원피스). **[제 옷]**: 모델이 원래 입은 옷.
- 입은 옷은 저장되어 **게임을 끄고 켜도 그대로**다.
- 웹에서 받아 입기: `characters.json`에 `"outfitUrls": ["https://…/옷.vrm", "https://…/옷.zip"]`을 적으면 [옷 바꾸기]가 아직 안 받은 주소에서 하나를 받아 입는다. 받은 파일은 `문서\짭풍명월\Characters\outfits`에 남는다. VRoid로 만든 VRM이어야 옷이 바뀐다(옷 조각 이름 `…_CLOTH`).

### 캐릭터가 너무 밝을 때 (`brightness`)

흰 머리·흰 옷 캐릭터는 밤이나 그늘에서도 혼자 하얗게 떠 보일 수 있다. `characters.json`에 밝기 배수를 적으면 낮춘다.

```json
"brightness": [ { "file": "AvatarSample_G.vrm", "value": 0.7 } ]
```

1 = 그대로, 0.8 = 20% 어둡게 (0.2~1.5). 기본으로 `AvatarSample_G`가 0.7이다. 내 폴더 `characters.json`에 적으면 게임 폴더 목록과 합쳐지고 같은 파일은 내 것이 이긴다. 게임을 다시 켜면 바뀐다.

## 3. 언제 바뀌나

| 대상 | 바뀌는 때 |
|---|---|
| 내 캐릭터 | 캐릭터 창 **[새로고침]** (그 자리에서) |
| NPC | **게임을 다시 켜면** (이미 서 있는 사람은 그대로) |

## 4. 주의할 점

- 키는 1.0~2.2m로 만든다. 밖이면 1.6m로 맞춘다.
- 남이 만든 VRM은 그 파일의 **사용 허락**을 지킨다. 캐릭터 창 왼쪽 카드에 허락 내용이 나오고, "만든 사람만" 모델이면 노란 경고가 뜬다.
- 캐릭터 하나가 15~20MB라, 그 캐릭터가 처음 나오는 낚시터에 들어갈 때 조금 더 기다릴 수 있다.
- 모자·옷 같은 **의상은 몸에 입혀지지 않고 능력치만** 붙는다. 몸에 보이는 장비는 낚싯대뿐이다.

## 5. 함께 들어 있는 캐릭터 (CC0)

VRoid 프로젝트(pixiv)가 VRoid Studio 샘플로 **CC0**(누구나 자유롭게 쓰고 고치고 다시 배포 가능)로 공개한 모델이다. 각 파일의 VRM 정보에도 "누구나 사용·재배포·상업 이용 허락, 표기 불필요"로 적혀 있다.

| 파일 | 쓰임 |
|---|---|
| `Sendagaya_Shino.vrm` (千駄ヶ谷篠) | 기본 캐릭터 (여자) — 처음 시작하면 이 캐릭터 |
| `HairSample_Male.vrm` | 기본 캐릭터 (남자), 남자 NPC |
| `Sakurada_Fumiriya.vrm` (桜田史利矢), `Base_Male.vrm` | 남자 NPC |
| `AvatarSample_D`(千駄ヶ谷渋)·`E`(ビビ)·`F`(ヴィータ)·`G`(ヴィクトリア・ルービン), `HairSample_Female`, `Base_Female` | 여자 NPC |
| `AvatarSample_D_Darkness.vrm` | 목록에서 고를 수만 있음 |

개발 쪽 구조는 [16 문서](../16-vrm-characters.md).
